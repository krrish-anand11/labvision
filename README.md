# LabVision 🔬
**Turn plain-English physics word problems into interactive 60fps simulations and step-by-step equation breakdowns in your browser.**

Built for the **Global STEM Innovation Challenge 2026 (GSIC 2026)**.

## Live Demo
👉 **[Launch LabVision](https://labvision-physics-si-27sk.bolt.host)**

## Key Features
* **Smart Word-Problem Parser:** Extracts physical quantities (`m/s`, `degrees`, `kg`, `m`) and planetary gravity (`Earth`, `Moon`, `Mars`) from pasted textbook problems using client-side JavaScript regex/NLP rules.
* **Interactive 60fps HTML5 Canvas:** Renders live projectile trajectories, inclined ramps, and pendulums with velocity vectors, telemetry overlays, and real-time parameter sliders.
* **Step-by-Step Formula Breakdown:** Dynamically computes and displays kinematics equations alongside the visual simulation.
* **Zero-Cost, Client-Side Execution:** Runs 100% in the browser with zero external API keys or servers.

## Tech Stack
* React + TypeScript
* Tailwind CSS
* HTML5 Canvas
* Vite
